# 项目命名与简介

> 参考：《高性价比人生指南》（HowToLiveBetter）、《人生进阶指南》
> 两者的共同点：**中文名 = 一个大白话的承诺 + 「指南」**；英文仓库名是一句完整的英文短语；简介第一句就讲清楚「讲什么、凭什么信」。

---

## 1. 名称候选

| # | 中文名 | 仓库名 | 一句话口号 | 优点 | 缺点 |
|---|---|---|---|---|---|
| **已选** | **AI 提效指南** | `WorkSmarterWithAI` | 少踩坑、少花钱，让 AI 帮你把工作做快 | 一看就懂；「AI 提效」是职场人搜 AI 时的高频词，利于平台搜索和 SEO | 「提效」用得多，要靠口号和「亲测」做出记忆点 |
| 2 | AI 干活指南 | `HowToWorkWithAI` | 不讲概念，只讲能用：让 AI 真正替你把活干了 | 口语、好记，和 HowToLiveBetter 的命名能对上 | 偏口语，正式场合引用略显随意 |
| 3 | AI 好用指南 | `AIThatWorks` | 各行各业亲测好用的 AI，一篇讲清楚 | 稳妥，"好用"对应实测和评测 | 比较普通，搜索时容易和其他项目重名 |
| 4 | 亲测好用的 AI | `TestedAI` | 每一个都实测过，写明日期和版本 | 突出"实测"这个最大卖点 | 不像书名，像栏目名 |
| 5 | 打工人 AI 手册 | `AIForWork` | 给普通打工人的 AI 提效手册 | 人群定位清楚，有传播感 | 把老板、自由职业者、学生排除在外了 |

### 已选：**AI 提效指南 · WorkSmarterWithAI**

- 一看就懂：讲的就是用 AI 把工作做得更快、更省，Skill、工作流、AI 应用三类内容都在这个范围里。
- 好搜：「AI 提效」是公众号、小红书、B 站和搜索引擎上的高频词，名字本身就是搜索入口。
- 英文名 `WorkSmarterWithAI` 取自 "work smarter, not harder"，海外读者也看得懂。
- 记忆点靠「亲测」来补：README、头图、About 都突出「每篇写明实测日期和版本」，跟泛泛的提效合集区分开。
- 副标题固定为：**各行各业亲测好用的 Skill、工作流和 AI 应用**，用在 README、网站标题、SEO 描述里。

> 上线前建议检查：GitHub 上 `WorkSmarterWithAI` 是否已被占用，`.com` / `.cn` 域名是否可注册，公众号 / 小红书 / B 站上同名账号是否可用。

## 2. GitHub About（右侧简介栏）

GitHub 的 About 最多 350 字符。参考 HowToLiveBetter：**先列覆盖范围，再说每条写明了什么，最后一句讲可信度。**

**中文版（推荐，约 130 字）**

```
AI 提效指南：各行各业亲测好用的 Skill、工作流和 AI 应用。法律、财务、电商、新媒体、设计、教育、开发……每篇写明适合谁、要花多少钱、最后实测日期和版本；评测统一打分并披露合作；自研的 Skill 和工作流可直接下载。持续更新，过期会标出来。
```

**中英双语版（如果要做英文版）**

```
AI 提效指南 | Field-tested AI skills, workflows and apps for real jobs. 各行各业亲测好用的 Skill、工作流和 AI 应用：每篇写明适合谁、花多少钱、实测日期和版本，自研 Skill 和工作流可直接下载，持续更新。
```

**Website**：`https://<你的域名>`（上线前先填 Cloudflare Pages 给的 `*.pages.dev` 地址）

**Topics**（GitHub 话题标签，最多 20 个，影响搜索和推荐）：

```
ai  ai-tools  claude-code  codex  agent-skills  claude-skills  mcp  workflow
n8n  dify  coze  automation  prompt-engineering  productivity  tutorial
handbook  chinese  vitepress  awesome
```

**勾选项**：Releases（放可下载的 Skill 包）、Discussions（读者提问、投稿推荐），不勾 Packages 和 Deployments。

## 3. 网站首页 Hero（参考图 3 的头图）

```
[图标] AI 提效指南

少踩坑、少花钱，
让 AI 帮你 把工作做快

法律 · 财务 · 电商 · 新媒体 · 设计 · 教育 · 开发 · 行政人事

[ {{N}} 篇实测 ]  [ {{N}} 个可下载 Skill ]  [ {{N}} 个工作流 ]  [ 可按行业筛选 ]
```

- 「把工作做快」用主题色高亮，对应参考图 3 里的"寿命、金钱和自由"。
- 四个徽章里的数字由脚本从 frontmatter 统计后自动写入（参考 HowToLiveBetter 的 `sync-stats.mjs`），README 顶部的 `og.png` 也用这张图。
- 内容还少的时候（< 20 篇），徽章先写"按行业筛选 / 写明实测日期 / 可直接下载 / 持续更新"这类不带数字的描述，免得数字太小显得单薄。
