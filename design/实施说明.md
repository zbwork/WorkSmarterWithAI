原设计可实施，已采用 VitePress 1.6.4 稳定版和 pnpm。原始设计与 README 草案保留。

## 修正

1. 加入 unverified 状态，允许 verified 为空；防止初始化时虚构亲测记录。当前 6 篇仅为方法示例，不以篇数填充 15–20 篇伪实测。
2. Skill 类型加入 format：skill / mcp / prompt。提示词包不能冒充已安装测试的 Agent Skill。
3. sponsored 对所有文章必填；商业合作另填 disclosure。评测强制用例与分项评分，按统一权重计算。
4. cost、updated 明确必填；平台费用可标为“按所用工具计费”，避免把免费源码误写成免费使用。
5. llms.txt 是目录，llms-full.txt 是全文；工具是否能读取受网络和上下文限制。查询 Skill 的 ZIP 随附目录和全文快照。
6. 第一版中文位于根路径；未来英文可加 /en/，无需移动中文链接。
7. 采用 CC BY 4.0 正文、MIT 代码，与原 README 默认选择一致；域名未设置，初始发布目标为 GitHub Pages，可迁移 Cloudflare Pages。
8. 更新记录优先读取 Git 初次提交与实质字段变更；无 Git 历史时使用 created / updated / verified。GitHub CI 使用完整历史。
9. 新增 GitHub Pages 自动部署。Cloudflare/Vercel 的 PR 预览需要先连接对应平台，不在未配置时声称已启用。
10. 未配置评论、统计、付费存储、国内镜像和英文内容；这些依赖后续具体服务与内容决策。

## 视觉方案

浅色纸面、深绿色强调、清晰留白；首页介绍、分类入口、行业与最新内容各自承担一个任务。教程沿用三栏阅读。筛选目录在桌面左侧固定，移动端自然折叠为上方条件区。入场、链接与卡片反馈采用短过渡，尊重减少动态效果设置。
