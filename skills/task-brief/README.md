# 让 AI 先问清楚你要什么

这是一个先问三个问题、再起草通知或短文的技能包。入口是 `SKILL.md`，包含标准的 name 与 description。

- 图形界面平台：按网站对应平台入门页的官方文档指引导入。
- Codex：在练习项目的 `.agents/skills/task-brief/` 下放入本文件夹，按官方技能入口调用。
- `prompt.md` 保留为普通聊天指令，复制它不等于已安装技能。

四个平台尚未完成技能导入和调用实测，当前是草稿；至少两个平台通过实测后才进入网站默认列表。请保留失败与修正记录，不要把聊天截图当作安装成功的证据。
