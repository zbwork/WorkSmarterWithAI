# 豆包工作

用于工作任务的办公智能体。普通聊天的实测不代表这里的技能导入已经通过。

## 安装、登录与费用

从[官网](https://www.doubao.com/work)获取客户端，按提示登录。费用说明整理于 2026-11-16，尚未核对账号套餐和额度，请以客户端及官网显示为准。

## 怎么导入技能

以下依据[官方技能说明](https://www.doubao.com/work/docs/zh-cn/articles/081010973544-skills)整理（查阅于 2026-11-16）。这部分没有实际安装验证。

1. 下载你想用的技能包，解压。文件夹里应有 <Term id="skill-md" />。
2. 在客户端左侧打开“插件·技能·伙伴”，进入“技能”。
3. 点“+ 添加”→“上传技能”，选择技能文件或文件夹。
4. 到技能管理列表中确认是否出现了该技能。

**待补截图**：技能入口、上传位置、安装后的列表。聊天截图不能证明技能已安装成功。

## 怎么调用

新建一个工作任务，输入 / 或 @ 查找技能，也可以从“更多技能”选择。选中后，用日常语言说你要做什么。
