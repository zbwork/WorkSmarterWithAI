# 把模糊需求变成一份任务简报

适合经常需要把工作交给 AI、却发现输出偏题的人。这是可复制的提示词包，使用费用由所选 AI 工具决定。

## 能解决什么问题

“帮我写篇文章”没有说明读者、材料和完成标准。先整理需求，能让你更容易发现信息缺口，也更容易检查结果。

## 准备工作

选一项真实任务，整理允许使用的材料。先用下面的虚构案例练习，不需要上传客户资料。

## 操作步骤

### 1. 写下原始需求

```text
我想把一场关于远程协作的访谈，整理成公众号文章。
读者是刚开始带团队的人。
我有访谈记录，但还没确定文章结构。
```

### 2. 让 AI 整理任务简报

```text
先不要直接完成任务。请把我的需求整理为任务简报：
目标读者、最终交付物、已有输入、必须遵守的约束、验收标准。
分清“已确认信息”和“待确认问题”。
缺失的信息不要猜测，最多提出三个会改变结果的问题。
我确认简报后再开始执行。
```

### 3. 确认关键约束

补充篇幅、语气、材料使用范围。把“写得好”改成可检查条件，例如：每个引用均可追溯到原记录，不编造访谈观点。

## 示例结果

以下为人工编写的示例，**不是工具实测输出**：

| 字段 | 内容 |
| --- | --- |
| 读者 | 新任团队负责人 |
| 输入 | 已提供的访谈文字 |
| 输出 | 文章提纲，确认后再写正文 |
| 约束 | 不添加未出现的故事和数字 |
| 验收 | 每个核心观点能指回访谈段落 |

## 常见问题

**AI 直接开始写正文？** 重申先输出简报，并将任务分两次对话执行。

**需要多久？** 取决于需求复杂度；本示例未测量节省时间。
