# 让 AI 先问清楚你要什么

<ArticleSummary />

你说“帮我写个通知”，AI 却不知道写给谁、通知什么。先让它问三个问题，通常更容易把事情说清楚。

## 1. 打开豆包

打开 [豆包网页版](https://www.doubao.com/chat/)，找到“发消息”输入框。需要登录时，先按页面提示登录。

## 2. 把这段话发给它

先完整复制这个例子，不需要下载或安装文件。

<PromptBox>

我想写一份周末读书会的通知，但还没想好怎么说。

请先问我三个最需要确认的问题，一次问一个。等我回答完，再帮我写一段适合发在微信群的通知，控制在 150 字以内。

没有告诉你的时间、地点和费用，请留空让我补，不要自己编。

</PromptBox>

![豆包输入框的位置与发送按钮，图中使用的是会议练习文字](/images/doubao-input.webp)

## 3. 回答它的问题

比如它问“什么时候、在哪里”，你可以回复“本周六下午 2 点，社区二楼阅览室”。如果问到你还没决定的事，就回复“还没定，先留空”。

## 做完得到什么？

你会得到一段通知草稿。确认里面的时间、地点、费用和报名方法都正确，再发出去。

如果它没问问题就开始写，补一句：“先问我问题，等我回答后再写。”

## 换成你自己的事情

把第一句换成“我想写一封请假邮件”或“我想准备一份面试自我介绍”，后面的问答方法也可以照着试。
