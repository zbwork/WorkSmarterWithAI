# 把个人经验整理成账号定位和首期内容

从自己确实会的事出发，确定读者、内容边界和前三篇选题。

下面使用虚构练习材料。示例结果为人工编写，供核对内容和格式。

::: platform doubao

## 1. 打开工具，准备材料

打开 [豆包网页版](https://www.doubao.com/chat/)，按页面提示完成登录。在对话输入框里发送下一步的完整文字。先用练习材料做一遍，再换成自己的资料。

## 2. 复制这段话并发送

<PromptBox>

请帮我整理一个虚构自媒体账号的定位，不编经历、不承诺涨粉。
我的情况：在租房里养了半年绿萝，记录过浇水日期和两次换盆过程；只有手机，周末能拍摄一小时。
想服务的人：第一次在出租屋养绿萝的人。
边界：分享自己的记录，不冒充园艺专家；不讲所有植物通用的养护结论。
请给：一句话定位、适合写/暂时不写的内容、前三篇选题、每篇需要的已有素材、尚需核实的事实。选题应能用这些材料完成。

</PromptBox>

## 3. 对照结果，修正遗漏

下面是一种人工整理的参考结果，不是工具实测输出。AI 的措辞可以不同，事实、限制和关键内容应一致。

- 定位：一个租房新手的绿萝养护记录。
- 第一篇：我怎样记录浇水日期；素材是日期记录。
- 第二篇：第一次换盆准备了什么；素材是换盆过程照片。
- 第三篇：两次换盆时我遇到的问题；素材是两次记录的对照。
- 暂时不写：没有养过的植物、保证成活的养护结论、没有记录的生长效果。

如果回答超出了要求，可以继续发送：

<PromptBox>

逐条标出“有记录支撑”或“需要补充”。没有素材的选题先移到后续清单，不要替我编一段经历。

</PromptBox>

## 4. 换成自己的材料

换成自己有持续记录的经历，选一篇素材最完整的先做。发布前核对照片、时间和表述，再逐步更新。

审阅后选中需要的结果复制到自己的文档，保留原始材料，方便以后复核。

:::

## 检查一下

定位、经历和素材对应真实情况。养护事实需另行核实，不把个人记录写成适用于所有环境的规则。
