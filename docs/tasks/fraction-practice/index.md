# 按教学目标生成一页分数练习

限定知识点、题量和答案，制作一份能由教师逐题检查的练习。

下面使用虚构练习材料。示例结果为人工编写，供核对内容和格式。

::: platform doubao

## 1. 打开工具，准备材料

打开 [豆包网页版](https://www.doubao.com/chat/)，按页面提示完成登录。在对话输入框里发送下一步的完整文字。先用练习材料做一遍，再换成自己的资料。

## 2. 复制这段话并发送

<PromptBox>

请为小学同分母分数知识点设计一页练习，不涉及通分、带分数或乘除法。
教学目标：会算同分母分数加减，会比较同分母分数大小。
出题要求：四道计算题、两道比较题；计算结果在 0 到 1 之间；分母只使用 4 或 8。
先给学生版，不含答案；再给教师版，列答案和一句解题依据。用普通文字写分数，例如 1/4。不要声称符合某个地区教材。

</PromptBox>

## 3. 对照结果，修正遗漏

下面是一种人工整理的参考结果，不是工具实测输出。AI 的措辞可以不同，事实、限制和关键内容应一致。

**人工编写的对照练习**

1. 1/4 + 2/4 = 3/4
2. 3/4 − 1/4 = 2/4（也可写 1/2）
3. 5/8 − 2/8 = 3/8
4. 1/8 + 3/8 = 4/8（也可写 1/2）
5. 3/8 ＜ 5/8
6. 2/4 ＞ 1/4

学生版应去掉等号后的答案及比较符号；教师版再保留。

如果回答超出了要求，可以继续发送：

<PromptBox>

检查六题是否都只考同分母分数。若出现通分、负数或大于 1 的结果，请替换该题。把学生版和答案版分开。

</PromptBox>

## 4. 换成自己的材料

替换成实际知识点、题量和限制，审核后复制到文档排版，打印前再次确认学生版没有答案。

审阅后选中需要的结果复制到自己的文档，保留原始材料，方便以后复核。

:::

## 检查一下

教师逐题算一遍，确认题量、答案和本班进度。约分是否属于本次要求由教师决定，不直接采用 AI 的教材适配判断。
