# 把一周工作记录整理成周报

把已完成、进行中和需要协助的事分开，得到一份可核对的周报。

下面使用虚构练习材料。示例结果为人工编写，供核对内容和格式。

::: platform doubao

## 1. 打开工具，准备材料

打开 [豆包网页版](https://www.doubao.com/chat/)，按页面提示完成登录。在对话输入框里发送下一步的完整文字。先用练习材料做一遍，再换成自己的资料。

## 2. 复制这段话并发送

<PromptBox>

请把以下虚构工作记录整理成一份给直属同事看的周报，分为“已完成、进行中、下周计划、需要协助”。每项写清进展，不添加业绩、日期或完成率。
周一：整理了 12 条用户反馈，交给产品同事。
周二：培训资料初稿写完，还没有评审。
周三：和设计同事确认了两张配图，其中一张仍待修改。
周四：联系了 3 家供应商，收到 2 份报价，还差 1 份。
周五：计划下周一请产品同事评审培训资料，时间还未确认。
请区分“初稿完成”和“整件事完成”，待确认的内容直接写待确认。全文不超过 250 字。

</PromptBox>

## 3. 对照结果，修正遗漏

下面是一种人工整理的参考结果，不是工具实测输出。AI 的措辞可以不同，事实、限制和关键内容应一致。

| 栏目 | 人工整理的参考内容 |
| --- | --- |
| 已完成 | 整理并提交 12 条用户反馈；完成培训资料初稿 |
| 进行中 | 培训资料待评审；一张配图待修改；已收 2 份报价，另 1 份待回 |
| 下周计划 | 邀请产品同事评审培训资料，拟下周一，时间待确认 |
| 需要协助 | 请产品同事确认评审时间 |

如果回答超出了要求，可以继续发送：

<PromptBox>

请检查每项进度是否和原记录一致。“培训资料初稿完成”不能改成“培训交付完成”。删掉没有依据的评价。

</PromptBox>

## 4. 换成自己的材料

把原始记录替换成自己的工作日志。发送前去掉客户身份等无关信息，补充已确认的截止时间，审阅后复制到周报文档。

审阅后选中需要的结果复制到自己的文档，保留原始材料，方便以后复核。

:::

## 检查一下

核对 12 条、3 家和 2 份这三个数字。不要把计划写成已完成，也不要把未确认的时间写死。
