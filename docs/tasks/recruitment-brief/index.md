# 把招聘需求写成一份岗位说明

用明确的工作内容和条件写岗位说明，缺失的信息单独列出来。

下面使用虚构练习材料。示例结果为人工编写，供核对内容和格式。

::: platform doubao

## 1. 打开工具，准备材料

打开 [豆包网页版](https://www.doubao.com/chat/)，按页面提示完成登录。在对话输入框里发送下一步的完整文字。先用练习材料做一遍，再换成自己的资料。

## 2. 复制这段话并发送

<PromptBox>

请根据以下虚构需求写一份“活动执行助理”的岗位说明，分为岗位目标、主要工作、必需能力、工作安排、待确认信息。只用提供的事实，不添加薪资、学历、年龄、性别或福利条件。
团队：一家社区活动机构。
工作：跟进报名名单、准备物料清单、活动当天签到、活动后整理反馈。
能力：会整理表格，能清楚地与参与者沟通。
安排：每周约两场活动，具体排班待定；工作地点由活动安排决定。
薪资和合同形式尚未确定。
语言直接，不写“抗压能力强”“年轻有活力”等空话。

</PromptBox>

## 3. 对照结果，修正遗漏

下面是一种人工整理的参考结果，不是工具实测输出。AI 的措辞可以不同，事实、限制和关键内容应一致。

**岗位：活动执行助理**

- 目标：把报名、物料、签到和反馈整理清楚。
- 工作：维护报名表；核对物料；安排签到；汇总活动反馈。
- 必需能力：能整理表格、清楚沟通。
- 安排：每周约两场活动；排班和地点需按活动确认。
- 待确认：薪资、合同形式、具体排班。

如果回答超出了要求，可以继续发送：

<PromptBox>

把“任职要求”里没有对应实际工作的条件删掉。将未提供的薪资、合同形式保留为待确认，不要补一个看起来合理的范围。

</PromptBox>

## 4. 换成自己的材料

先用真实工作清单替换练习材料，整理缺失问题向用人负责人确认，再发布岗位说明。

审阅后选中需要的结果复制到自己的文档，保留原始材料，方便以后复核。

:::

## 检查一下

逐条核对岗位职责和条件是否来自需求。正式发布前让招聘负责人确认薪资、排班、合同形式和最终文案。
