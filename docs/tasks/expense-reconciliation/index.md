# 核对两张报销表的金额差异

按单据编号比较两份表，找出需要人工核对的差异。

下面使用虚构练习材料。示例结果为人工编写，供核对内容和格式。

::: platform doubao

## 1. 打开工具，准备材料

打开 [豆包网页版](https://www.doubao.com/chat/)，按页面提示完成登录。在对话输入框里发送下一步的完整文字。先用练习材料做一遍，再换成自己的资料。

## 2. 复制这段话并发送

<PromptBox>

请核对以下两份虚构报销记录，只按单据编号匹配，金额单位均为元。
提交表：A01 交通 90；A02 物料 120；A03 打印 80。
登记表：A01 交通 90；A02 物料 150；A03 打印 80。
输出：编号、提交金额、登记金额、差额（登记减提交）、是否需要核对；最后分别计算两表合计。
不要推断谁填错，不判断票据是否合规，不修改任何金额。缺少原始凭证时说明需要人工核对。

</PromptBox>

## 3. 对照结果，修正遗漏

下面是一种人工整理的参考结果，不是工具实测输出。AI 的措辞可以不同，事实、限制和关键内容应一致。

| 编号 | 提交金额 | 登记金额 | 差额 | 需要核对 |
| --- | ---: | ---: | ---: | --- |
| A01 | 90 | 90 | 0 | 否 |
| A02 | 120 | 150 | 30 | 是 |
| A03 | 80 | 80 | 0 | 否 |
| 合计 | 290 | 320 | 30 | 原始凭证待核对 |

这张表只标出差异，无法据此判断哪份记录正确。

如果回答超出了要求，可以继续发送：

<PromptBox>

请重算两张表的合计，并说明差额采用“登记减提交”。不要把金额差异自动归因于多报、少报或录入错误。

</PromptBox>

## 4. 换成自己的材料

把两份表的编号和金额复制出来，先检查重复编号及单位。金额核对结果交由负责人员结合原始凭证确认。

审阅后选中需要的结果复制到自己的文档，保留原始材料，方便以后复核。

:::
