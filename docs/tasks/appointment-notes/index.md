# 把零散记录整理成就诊提问单

整理症状时间线、已用药信息和待询问问题，供就诊时核对。

下面使用虚构练习材料。示例结果为人工编写，供核对内容和格式。

::: platform doubao

## 1. 打开工具，准备材料

打开 [豆包网页版](https://www.doubao.com/chat/)，按页面提示完成登录。在对话输入框里发送下一步的完整文字。先用练习材料做一遍，再换成自己的资料。

## 2. 复制这段话并发送

<PromptBox>

请只整理以下虚构材料，生成一页就诊沟通提纲，不诊断、不建议用药、不判断轻重缓急。
材料：周一开始发现一只手腕在使用鼠标后不舒服；周二休息时感觉减轻；周三又出现。具体持续多久、程度多强还没有记录。
目前是否使用药物、既往病史和过敏史都未提供，不能默认没有。
输出三部分：已经知道的时间线、需要本人补充的信息、准备向医生询问的问题。每条注明来自原文还是待补充。不要推测病因。

</PromptBox>

## 3. 对照结果，修正遗漏

下面是一种人工整理的参考结果，不是工具实测输出。AI 的措辞可以不同，事实、限制和关键内容应一致。

| 已知记录 | 来源 |
| --- | --- |
| 周一使用鼠标后手腕不适 | 原文 |
| 周二休息时感觉减轻 | 原文 |
| 周三再次出现 | 原文 |

**待补充**：具体部位、程度、持续时间、是否受伤、已用药物、病史和过敏史。

**准备询问**：这些记录还缺哪些信息？下一步需要怎样评估？哪些变化需要及时联系医疗人员？

如果回答超出了要求，可以继续发送：

<PromptBox>

删掉病名、病因猜测和药物建议。“未提供”不能改成“无”。请保留原始记录和待补充信息的区别。

</PromptBox>

## 4. 换成自己的材料

将虚构材料换成自己愿意提供的必要记录，去掉身份信息。保存成一页提纲，就诊时带上真实用药记录并向医生确认。

审阅后选中需要的结果复制到自己的文档，保留原始材料，方便以后复核。

:::

## 检查一下

本人核对每一条记录，药名及剂量按真实记录填写。AI 的结果只作参考，以医生或专业人员意见为准，不用它决定是否就医或拖延就医。

## 参考资料

整理就诊问题、记录需要告诉医生的信息和用药清单，可参考 [NHS：就诊时可以问什么](https://www.nhs.uk/nhs-services/gps/what-to-ask-your-doctor/)（查阅：2026-11-17）。本文仅演示资料整理。
