# 把账号定位变成一周选题表

围绕同一批读者安排三个选题，写清每条内容要解决什么问题。

下面使用虚构练习材料。示例结果为人工编写，供核对内容和格式。

::: platform doubao

## 1. 打开工具，准备材料

打开 [豆包网页版](https://www.doubao.com/chat/)，按页面提示完成登录。在对话输入框里发送下一步的完整文字。先用练习材料做一遍，再换成自己的资料。

## 2. 复制这段话并发送

<PromptBox>

请给以下虚构账号安排一周三个选题，不编造热点、搜索量或数据。
账号读者：刚入职、需要独自做饭的人。
内容边界：普通家庭厨房里的省时做饭经验，不提供减脂、疾病饮食建议。
现有材料：一次下班做番茄鸡蛋面的照片；一个洗菜收纳的短视频；一份做饭前检查食材的清单。
发布频率：周二、周四、周日，各一篇。
请输出表格：日期、读者问题、标题、使用哪份材料、需要补拍什么。三个选题不要讲同一件事。标题不使用夸张的效果承诺。

</PromptBox>

## 3. 对照结果，修正遗漏

下面是一种人工整理的参考结果，不是工具实测输出。AI 的措辞可以不同，事实、限制和关键内容应一致。

| 日期 | 读者问题 | 选题示例 | 已有材料 |
| --- | --- | --- | --- |
| 周二 | 下班后先做什么 | 下班做一碗番茄鸡蛋面，先后顺序怎么排 | 做面照片 |
| 周四 | 洗菜后怎么收拾 | 我的洗菜和收纳步骤 | 洗菜视频 |
| 周日 | 开始做饭才发现缺东西 | 做饭前先看这张食材清单 | 检查清单 |

补拍内容应围绕实际步骤，例如缺少的准备过程，不能要求拍不存在的效果对比。

如果回答超出了要求，可以继续发送：

<PromptBox>

把三个选题的读者问题分别用一句话说清。如果两个问题一样，换掉其中一个。不要新增没有素材支撑的效果。

</PromptBox>

## 4. 换成自己的材料

换成自己的读者定位、素材和可发布次数。先做能完成的内容，再根据实际反馈调整，不把 AI 的选题预测当作流量保证。

审阅后选中需要的结果复制到自己的文档，保留原始材料，方便以后复核。

:::

## 检查一下

每个选题都要有现成材料或明确的补拍清单。日期是排期，不代表平台流量规律；发布前核对图片授权。
