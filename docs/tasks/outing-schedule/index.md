# 把已确认的行程排成半日出行表

根据已知时间和步行限制安排行程，把未确认事项留在核对清单里。

下面使用虚构练习材料。示例结果为人工编写，供核对内容和格式。

::: platform doubao

## 1. 打开工具，准备材料

打开 [豆包网页版](https://www.doubao.com/chat/)，按页面提示完成登录。在对话输入框里发送下一步的完整文字。先用练习材料做一遍，再换成自己的资料。

## 2. 复制这段话并发送

<PromptBox>

请根据以下虚构信息安排一次半日出行，不搜索或编造实际地点、营业时间、票价。
参加者：两位成人、一名孩子。地点用 A 馆和 B 公园代称。
已确认：预约 A 馆 10:00 入场，计划参观 60 分钟；家到 A 馆路程预留 30 分钟；A 馆到 B 公园步行预留 15 分钟；13:00 前回家，从 B 公园回家预留 30 分钟。
要求：入场前留 15 分钟缓冲；参观后休息 15 分钟；公园停留 30 分钟。餐饮、厕所位置、天气尚未核实。
输出时间表和出发前核对清单。若条件冲突，请指出，不要悄悄缩短路程。

</PromptBox>

## 3. 对照结果，修正遗漏

下面是一种人工整理的参考结果，不是工具实测输出。AI 的措辞可以不同，事实、限制和关键内容应一致。

| 时间 | 安排 |
| --- | --- |
| 9:15—9:45 | 从家出发到 A 馆 |
| 9:45—10:00 | 入场缓冲 |
| 10:00—11:00 | 参观 |
| 11:00—11:15 | 休息 |
| 11:15—11:30 | 前往 B 公园 |
| 11:30—12:00 | 公园停留 |
| 12:00—12:30 | 回家 |

餐饮和厕所位置、当天开放情况及天气仍需另外确认。

如果回答超出了要求，可以继续发送：

<PromptBox>

逐段检查时间有没有重叠，保留 15 分钟入场缓冲和休息时间。没有给出的交通时长、票价和餐饮地点不要补写。

</PromptBox>

## 4. 换成自己的材料

用自己已经核实的地点、预约时间和路程替换材料。把待确认事项办妥后，再保存时间表给同行人。

审阅后选中需要的结果复制到自己的文档，保留原始材料，方便以后复核。

:::

## 检查一下

示例中的路程不是现实导航数据。出发前查官方预约信息和实际路线，确认同行者能接受的步行量，并准备变更安排。
