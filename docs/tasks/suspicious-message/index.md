# 把可疑通知整理成核验清单

从消息里找出需要核实的说法，规划不点击陌生链接的核验步骤。

下面使用虚构练习材料。示例结果为人工编写，供核对内容和格式。

::: platform doubao

## 1. 打开工具，准备材料

打开 [豆包网页版](https://www.doubao.com/chat/)，按页面提示完成登录。在对话输入框里发送下一步的完整文字。先用练习材料做一遍，再换成自己的资料。

## 2. 复制这段话并发送

<PromptBox>

请分析下面这条虚构通知，只列可疑点和核验办法，不凭文字断言发送者真实身份，也不要访问链接。
通知内容：“你的包裹异常，30 分钟内不处理将退回。点击本消息中的链接，填写银行卡号和验证码即可解锁。”
我还没有点击链接，也没有提供任何信息。
请输出：通知要求我做什么、哪些说法需要核实、可以通过哪些独立渠道核实、哪些信息不应该按这条通知提交。不要根据措辞判断是不是 AI 生成，不要声称识别准确率。

</PromptBox>

## 3. 对照结果，修正遗漏

下面是一种人工整理的参考结果，不是工具实测输出。AI 的措辞可以不同，事实、限制和关键内容应一致。

| 观察点 | 核验或处理方向 |
| --- | --- |
| “30 分钟内”制造紧迫感 | 不因催促直接操作，先核实订单状态 |
| 要求银行卡号和验证码 | 不通过这条消息提交这些信息 |
| 要求点消息里的链接 | 自行打开原购物应用或已知的官方渠道查询 |
| 包裹是否真的异常 | 用真实订单信息联系可信的官方客服核实 |

AI 只能辅助整理可疑点，不能认证消息来源。

如果回答超出了要求，可以继续发送：

<PromptBox>

不要只回答“这是诈骗”。请把可疑点和能独立核验的步骤分开，不把消息里的链接或电话作为唯一核验渠道。

</PromptBox>

## 4. 换成自己的材料

粘贴消息前删掉姓名、电话、订单号和真实链接。通过你自行找到的官方应用或渠道核实，不让 AI 代替身份确认。

审阅后选中需要的结果复制到自己的文档，保留原始材料，方便以后复核。

:::

## 检查一下

不点击练习之外收到的陌生链接，不向对方提供密码或验证码。即使语音、图片或文字看起来真实，也不能用它们代替独立核验；AI 不能保证判断准确。

## 参考资料

关于识别可疑消息、避免点击其中链接的建议，参考 [CISA：识别和报告钓鱼消息](https://www.cisa.gov/sites/default/files/2023-09/SOW-Web-Page-Animation_Phishing_Audio-Description.pdf)（查阅：2026-11-17）。
