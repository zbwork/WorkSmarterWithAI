# 根据商品资料写详情页文案

把规格、使用场景和未确认信息分开，避免写出不存在的卖点。

下面使用虚构练习材料。示例结果为人工编写，供核对内容和格式。

::: platform doubao

## 1. 打开工具，准备材料

打开 [豆包网页版](https://www.doubao.com/chat/)，按页面提示完成登录。在对话输入框里发送下一步的完整文字。先用练习材料做一遍，再换成自己的资料。

## 2. 复制这段话并发送

<PromptBox>

请根据以下虚构资料写一份帆布收纳袋详情文案，包含标题、三个特点、规格表、适合的使用场景和待确认信息。
资料：米白色；棉帆布；长 24 厘米、宽 16 厘米；拉链开合；无内袋；仅售收纳袋，不含拍摄道具。
可描述：放文具或小物件，是否装得下取决于物品尺寸。
未知：是否防水、承重、机洗条件、产地。
只使用已提供资料，不添加“防水”“抗菌”“大容量”“适合所有手机”等未经确认的承诺。全文不超过 300 字。

</PromptBox>

## 3. 对照结果，修正遗漏

下面是一种人工整理的参考结果，不是工具实测输出。AI 的措辞可以不同，事实、限制和关键内容应一致。

| 信息 | 可使用的写法 |
| --- | --- |
| 标题 | 米白色棉帆布拉链收纳袋 |
| 规格 | 24 × 16 厘米；无内袋 |
| 特点 | 拉链开合；棉帆布材质；用于分类收纳小物件 |
| 购买提醒 | 仅含收纳袋；请对照物品尺寸 |
| 待确认 | 防水情况、承重、清洗方式、产地 |

如果回答超出了要求，可以继续发送：

<PromptBox>

逐句检查有没有把未知信息写成卖点。把所有未经确认的性能删除，并把购买提醒放到规格表后面。

</PromptBox>

## 4. 换成自己的材料

使用经确认的商品规格、实拍信息和包装清单替换材料。未知项先问供应商，不让 AI 补齐。

审阅后选中需要的结果复制到自己的文档，保留原始材料，方便以后复核。

:::

核对材质、尺寸、包装清单和每一条性能表述。是否适配某个物品，要用实际尺寸或实物验证。
