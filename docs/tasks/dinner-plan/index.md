# 用现有食材安排一顿家常晚饭

把食材和时间限制说清楚，得到菜单及需要补买的清单。

下面使用虚构练习材料。示例结果为人工编写，供核对内容和格式。

::: platform doubao

## 1. 打开工具，准备材料

打开 [豆包网页版](https://www.doubao.com/chat/)，按页面提示完成登录。在对话输入框里发送下一步的完整文字。先用练习材料做一遍，再换成自己的资料。

## 2. 复制这段话并发送

<PromptBox>

请用下面的虚构家庭食材安排两位成人的一顿普通家常晚饭，给两个菜单备选，不提供医疗或减重饮食建议。
现有食材：鸡蛋 4 个、番茄 2 个、土豆 2 个、青菜 1 把、干面条 200 克。
家中有盐和食用油；不吃辣；未提供其他调味品。准备时间希望控制在约 30 分钟，只有一个灶眼。
请列出：菜单、用掉哪些现有食材、需要额外买什么、单灶操作顺序。时间只是估算。不能凭空增加肉类或调味品；没有说明过敏情况，不要假设适合所有人。

</PromptBox>

## 3. 对照结果，修正遗漏

下面是一种人工整理的参考结果，不是工具实测输出。AI 的措辞可以不同，事实、限制和关键内容应一致。

**备选一**：番茄鸡蛋面，加青菜。

- 使用：面条、番茄、鸡蛋、青菜，具体份量按食量调整。
- 补买：如果只用已有油盐，可以不额外购买；其他调味品必须另列。
- 顺序：洗切备料 → 处理鸡蛋和番茄 → 加水煮面 → 加青菜 → 检查食材熟透后盛出。

这只是人工菜单示例，实际用时取决于备料、火力和熟练程度。

如果回答超出了要求，可以继续发送：

<PromptBox>

请把新增但未列出的食材单独移到补买清单。按一个灶眼重新排顺序，不能同时安排两口锅加热。

</PromptBox>

## 4. 换成自己的材料

把数量、食量、厨具和忌口换成自己的情况。先选一个可完成的菜单，再确认家中调料，避免重复采购。

审阅后选中需要的结果复制到自己的文档，保留原始材料，方便以后复核。

:::

## 检查一下

核对过敏和忌口、食材新鲜程度及是否煮熟。30 分钟只是预估，不能为了赶时间省略必要烹饪步骤。
