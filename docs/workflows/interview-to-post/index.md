# 从一份访谈到一篇图文初稿

适合有访谈或课程文字材料、需要整理成文章的人。先产出提纲，再逐段写作，最后对照材料核查。

## 准备工作

准备已经获得使用授权的文字材料、读者画像和发布要求。正文使用化名，并删除无关的个人信息。

## 操作步骤

### 1. 建立材料清单

为段落编号，分别标记事实、受访者观点和作者解释。不要把受访者的个体经历改成普遍结论。

### 2. 先生成提纲

```text
只使用提供的材料，为新任管理者拟一份文章提纲。
每个小节写：要回答的问题、支撑段落编号、缺失的信息。
没有依据的内容列为待补充，不写进正文。
```

### 3. 分段写初稿

确认提纲后，一次只写一个小节。需要直接引语时保留原文，改写时不使用引号冒充原话。

### 4. 做一次来源检查

让 AI 列出正文中的数字、事实断言和引语，对照原段落逐条检查。核查结果仍需由人确认。

## 验收清单

- 每个引语与原文一致。
- 统计数字有来源，不凭空生成。
- 文章保留必要的限制条件。
- 标题没有夸大正文能支持的结论。

## 实际效果怎样记录

保存输入、提纲、初稿、人工修改稿和用时。当前文章是方法示例，尚未提供工具端实测结果。
