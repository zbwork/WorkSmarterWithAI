# 用同一份任务比较对话 AI

当你不知道选择哪个对话工具时，先用一份可复核的小任务做比较。这是测试方法教程，不是产品排名。

## 准备工作

准备同一份输入、同一条指令和同一套验收标准。分别记录工具、模型、套餐、日期以及是否启用联网功能。

## 操作步骤

### 1. 选择一个真实任务

例如：把一段 800 字的活动说明整理为报名须知，不遗漏时间、地点、费用和取消规则。

### 2. 提前确定验收标准

| 标准 | 如何检查 |
| --- | --- |
| 信息完整 | 逐项对照原文中的关键信息 |
| 没有编造 | 输出中的事实均能找到原文依据 |
| 格式可用 | 能直接放入目标文档，或只需少量编辑 |
| 过程可重复 | 多次测试，记录成功和失败 |

### 3. 保持条件一致

分别开启新对话，使用相同输入。不要给某个工具更多提示或额外样例。需要重试时记录原因和次数。

### 4. 计算实际投入

除产品费用外，记录检查、修改和重做时间。不要把某次理想输出的速度当作长期节省的时间。

## 记录表

```text
工具 / 模型：
测试日期 / 套餐：
输入材料与提示词：
运行次数与失败情况：
达到的验收条件：
人工修改与用时：
价格来源与查询日期：
```

## 常见问题

**免费与付费能直接比较吗？** 可以比较你的实际选择，但应标明套餐和预算约束，避免把差异归因于单一因素。
