# 把商品评论整理成用户反馈主题

适合需要阅读大量评论的运营同学。先用一小批公开、去标识化的评论验证方法，再扩大范围。

## 准备工作

准备带编号的评论文字，保留商品类别与时间范围，删除昵称、订单号和联系方式。不要把小样本比例当成全部用户的结论。

## 操作步骤

1. 把评论按主题归类，每条保留原编号。
2. 将正向反馈、负向反馈、功能请求分别整理。
3. 为每个主题列出支撑评论，不允许补充用户没说过的话。
4. 检查同一评论是否重复计数，核对样本数量。

```text
请分析这些评论。输出：主题、评论编号、原话摘录、需要验证的问题。
一条评论可以有多个主题，但统计时说明计数口径。
不要根据昵称推断年龄、性别或收入，不把猜测写成用户事实。
```

## 示例验收

“包装破损”可以归为物流或包装相关反馈，但不能直接断定是哪个环节造成。应将原因放在“待验证”栏。

## 结果边界

这能帮助整理信息，不能替代用户访谈和业务数据。当前为方法示例，未测量分类准确率；发布评测前需人工标注样本并复核。
