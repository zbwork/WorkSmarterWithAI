# 关于这本手册

给第一次用 AI、也不写代码的人。每篇围绕一件小事，告诉你打开什么、复制什么、做完得到什么。

## 谁在维护？

由 [zbwork](https://github.com/zbwork) 维护，所有正文和网站代码都公开在 [GitHub](https://github.com/zbwork/WorkSmarterWithAI)。

## 我们怎样写？

尽量用日常语言，能复制就不要求下载，能用截图说清楚就不堆术语。

实际跑过的教程会附上结果、日期和遇到的问题；还没跑过的会在文末说明。已试跑不代表每次回答都一样，也不等于已经通过新手测试。

我们希望每篇入门教程都能让一个没用过 AI 的人照着完成。第一课以 3 分钟为目标，后续会记录真实读者在哪一步卡住。
