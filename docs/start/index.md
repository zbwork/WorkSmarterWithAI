# 第一次用 AI，从这里开始

先做一件小事：**把三句话变成一张待办表。** 预计 3 分钟，不含注册登录。

不用安装软件，不用写代码，先用免费额度练习。

## 跟着第一课做

[开始：把会议记录变成待办表 →](/workflows/meeting-actions/)

这节课只有三步：

1. 打开豆包。
2. 复制教程里的文字，粘贴并发送。
3. 对照原话，检查表格里的人名和时间。

教程里有真实操作截图，也展示了 AI 写错后怎么改。
