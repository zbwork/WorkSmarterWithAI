# 从一个具体任务开始

你不需要先学会所有工具。先选一件重复发生、容易检查结果的小事。

## 1. 写清楚你要交付什么

把“想用 AI 提效”改成“把本周三次会议记录整理成一份待办清单”。写下输入材料、输出形式和完成标准。

## 2. 选一条路线

| 现在的需要 | 可以从这里开始 |
| --- | --- |
| 需要一份可重复使用的指令 | [结构化需求提示词包](/skills/task-brief/) |
| 需要完整的操作顺序 | [从会议记录到可执行待办](/workflows/meeting-actions/) |
| 不确定如何评价 AI 的回答 | [用同一份任务比较对话 AI](/apps/compare-chat-tools/) |
| 已有明确行业和工具 | [总览筛选](/catalog/) |

## 3. 用示例材料先走一遍

先用公开资料或手册提供的虚构样例。检查输出是否保留事实、是否编造信息、是否遗漏约束。再考虑带入自己的工作材料。

## 4. 记录这次实际结果

记录日期、工具与模型版本、输入、输出、人工修正和失败情况。一个流程跑通一次，不代表所有任务都可靠。

::: tip 怎样看验证状态
**待实测**是方法示例；**已实测**须有测试日期与版本；**待复测**表示超过 90 天未测试或作者已标记变化；**已停止维护**仅供历史查阅。
:::
